## Git e Github 

[git - guia prático](https://rogerdudler.github.io/git-guide/index.pt_BR.html)		
Guia introdutório que ensina os principais comandos do Git, abordando conceitos como repositórios, commits, branches e integração de alterações. Ideal para iniciantes que desejam aprender a controlar versões de projetos e colaborar no desenvolvimento de software.

[Git e Github para Iniciantes](https://www.youtube.com/watch?v=IBClN6VpJDw&list=PLlAbYrWSYTiPA2iEiQ2PF_A9j__C4hi0A)		
Playlist de vídeos para aprender sobre Git e GitHub, ferramentas utilizadas no controle de versão e na colaboração em projetos de software. Ideal para iniciantes que desejam aprender a versionar códigos, gerenciar repositórios e compartilhar projetos.

[Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/)	
Especificação que define um padrão para escrever mensagens de commit claras e organizadas. Ajuda a identificar o tipo de alteração realizada no código, como novas funcionalidades, correções de erros e mudanças na documentação, facilitando a leitura do histórico do projeto.

[README Generator](https://rahuldkjain.github.io/gh-profile-readme-generator/)		
O GitHub Profile README Generator é uma ferramenta gratuita que permite criar e personalizar o README do perfil do GitHub de forma fácil e rápida, sem precisar escrever todo o código manualmente.
